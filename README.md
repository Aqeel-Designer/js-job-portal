# Job Portal

A responsive job portal website built with HTML, CSS, and JavaScript. The project allows users to browse available jobs, search and filter listings, view job details, save jobs, and manage job postings using browser local storage.

## Features

- Browse available job listings
- Search jobs by keywords
- Filter jobs by different criteria
- View detailed job information
- Add new job listings
- Edit existing job listings
- Delete job listings
- Save jobs for later
- Apply for jobs
- Store job data using Local Storage
- Dynamically render job listings
- Responsive user interface

## Data Persistence

The project uses browser Local Storage to store job listings and saved job information. This allows data to remain available after refreshing or reopening the browser.

## Purpose

This project was built to practice JavaScript by developing a complete frontend application rather than separate small exercises. It focuses on DOM manipulation, dynamic data rendering, user interactions, Local Storage, search and filtering, and CRUD functionality.
